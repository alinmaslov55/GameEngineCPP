2. Rendering & Logging Performance

Implement Batch Rendering in Renderer2D

Currently, every single tile, sprite, particle, and UI character glyph triggers its own uniform uploads, VAO bind, and glDrawElements call (600+ draw calls per frame).
Improvement: Allocate a dynamic vertex buffer for N quads (e.g., 10,000 quads) + a texture slot array (0..15), push vertex data in DrawQuad, and issue a single glDrawElements call in Renderer2D::EndScene.

Cache Uniform Locations in Shader

glGetUniformLocation is queried on the GPU driver multiple times per quad every frame. Caching locations in an std::unordered_map<std::string, int> inside Shader avoids repeated string lookups.

Reduce Per-Frame Synchronous Log Flushing

Logger::Init sets both set_level(trace) and flush_on(trace). Because DrawQuad, Shader::Set*, and Buffer::Bind emit TRACE logs, the engine performs thousands of synchronous disk flushes per second.
Improvement:
Default log level to info or debug and flush_on(spdlog::level::warn).
Strip TRACE macros in Release builds (#ifdef NDEBUG).
Add a custom ring-buffer sink to display logs directly inside an ImGui Console Panel.

Track Active Particle Count

In Sandbox/src/main.cpp, Active Particles prints particleSystem->GetParticles().size(), which always equals the pool capacity (500). Adding GetActiveParticleCount() to ParticleSystem will report the real live count.
3. Scene Serialization & Asset Management

Complete Component & Asset Serialization (SceneSerializer.cpp)

Currently, saving a scene only saves Transform and SpriteRenderer::Color. Painted Tilemap data, assigned SpriteRenderer textures, ParticleSystem, BoxCollider2D, UIPanel, UILabel, and CameraComponent are lost when reloading a scene.
Improvement:
Store m_Filepath in Texture and AudioClip (this also allows the Inspector to display "test.png" instead of raw OpenGL ID "1").
Serialize Tilemap dimensions, tile grid array, and remaining components in SceneSerializer.

Remove Hardcoded Absolute Paths (C:/DEV/GameEngineCPP/...)

Sandbox/src/main.cpp uses machine-specific absolute paths. Adding a configurable asset root in ResourceManager (or setting CMake's working directory / post-build asset copy) makes the project portable.
4. Editor UX, Gameplay & Architecture

Edit / Play Mode Toolbar & Editor Camera

Add an Edit / Play / Stop toolbar:
Edit Mode: Pan and zoom freely with an EditorCamera (middle-mouse drag + scroll wheel) and paint tiles / move entities without running gameplay scripts or physics.
Play Mode: Serialize/clone the active scene in memory, run gameplay (Scene::Update), and restore the pre-play state on Stop.

Entity Renaming, Deletion & Component Removal

Replace read-only ImGui::Text in the Inspector with ImGui::InputText wired to Object::SetName.
Add "Delete GameObject" to the Hierarchy context menu (calling Scene::DestroyGameObject) and "Remove Component" to GameObject + Inspector headers.

Physics, Tile Walkability & Gravity

Tile::walkable in Tilemap.h is currently unused, and pressing SPACE in PlayerController.h increases Y indefinitely with no gravity returning the player to Y = 0.
Either wire up the already-linked box2d dependency (in CMakeLists.txt) or add tilemap walkability checks + simple vertical velocity/gravity to the isometric physics step.
