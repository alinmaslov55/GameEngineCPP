[P1] IMMEDIATE HIGH-ROI ALGORITHMIC & DATA-ORIENTED OPTIMIZATIONS
--------------------------------------------------------------------------------
[x] 1. Camera & Shadow Frustum Culling
    - Files: Engine/src/Scene/Scene.cpp, Engine/include/Engine/Renderer/PerspectiveCamera.h
    - Details:
      * Extract 6 frustum planes from ViewProjection matrix (Gribb-Hartmann method).
      * Tilemap culling: Intersect camera frustum rays with Y=0 XZ plane to get tight [minX..maxX, minZ..maxZ] bounds and skip off-screen tiles (currently loops all WxH tiles every frame).
      * Standee & Light culling: Fast SIMD sphere/AABB visibility test before adding to m_StandeeScratch and point light passes.
    - Impact: 5x-20x reduction in CPU vertex submissions and GPU vertex processing on medium/large scenes.

[x] 2. Standee Render Command Caching & Motion Math Deduplication
    - Files: Engine/src/Scene/Scene.cpp, Engine/include/Engine/Scene/Scene.h
    - Details:
      * Stop calling GetComponent<T>() up to 11 times per entity across GatherRenderContext, RenderPassShadowMap, and RenderPassCutoutStandees.
      * Deduplicate ResolveStandeeMotion() which currently recalculates wind phase and proximity rustle twice per frame for every shadow-casting standee.
      * Flatten into StandeeRenderCommand struct storing pointers, precomputed size/rot/wind/bend, and viewDepth.
      * Schwartzian Transform for sorting: Precompute viewDepth once in O(N) rather than re-evaluating glm::dot in std::sort comparator (O(N log N) redundant math).
    - Impact: 2x faster CPU Scene::Render preparation, removes RTTI dynamic_cast bottlenecks.

[x] 3. Ring-Buffered VBO Allocations in Renderer2D
    - Files: Engine/src/Renderer/Renderer2D.cpp, Engine/include/Engine/Renderer/Buffer.h
    - Details:
      * Current issue: Renderer2D::Flush() is called 5+ times per frame (shadow, terrain, standees, particles, UI), writing to offset 0 with glBufferSubData while previous draw calls may still be in-flight on GPU.
      * Allocate VBO with 3x capacity and monotonically increment vertex offset (m_CurrentVertexOffset), wrapping only between frames, or implement persistent mapped buffers (glBufferStorage + GL_MAP_PERSISTENT_BIT).
    - Impact: Eliminates GPU driver CPU stalls and internal driver buffer ghosting.

[x] 4. Direct Quad Emission for Ground Tiles
    - Files: Engine/src/Scene/Scene.cpp, Engine/src/Renderer/Renderer2D.cpp
    - Details:
      * Bypass 4x4 matrix multiplication (glm::translate * groundFlatRotation * glm::scale) for every tilemap quad.
      * Add dedicated Renderer2D::DrawGroundTile(center, sizeXZ, subTexture, ...) directly calculating XZ corner positions.
    - Impact: Saves 4 matrix-vector multiplies per tile, streamlining ground rendering.

    - Files: Engine/src/Scene/Scene.cpp, Engine/include/Engine/Scene/Scene.h
